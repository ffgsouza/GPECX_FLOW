# **App Name**: PriceWise

## Core Features:

- Product Catalog: Product registration, including related licenses.
- Cost Input: Configurable fields for inputting purchase prices (hardware and software) in USD.
- Currency Exchange: Input fields for daily exchange rates.
- Customs Fees: Configurable input fields for fees, such as clearance, consulting, and storage.
- Tax Configuration: Fields for inputting import and sales taxes, including II, IPI, PIS, COFINS, ICMS, and Simples Nacional.
- Automated Calculation: Automatic calculations using registered values for import costs, taxes, sales expenses, and profit margin to generate a final price. Displays a breakdown including the final sales price, total cost, and profit.

## Style Guidelines:

- Primary color: Dark blue (#3F51B5) to evoke trust and professionalism, aligning with financial calculations.
- Background color: Very light blue (#E8EAF6), close to white but still in the blue family.
- Accent color: Soft violet (#8E24AA), a hue analogous to blue but sufficiently contrasting in brightness and saturation to highlight important interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, offering a neutral and machined look appropriate for business apps.
- A clean, efficient, data-dense layout allowing the user to easily find data
- Simple and professional icons to represent various fees, taxes, and product categories.
